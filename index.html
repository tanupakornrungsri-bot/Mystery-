กรุณาคลิกเลือกบัตรเหตุการณ์ด้านบนเพื่อแสดงคำนวณ $P(E) = n(E) / n(S)$

ตารางบันทึกผลกิจกรรม

รอบ บัตร P(E) ผลทอย ผลได้/เสีย รวม
องค์ความรู้เรื่องความน่าจะเป็น:
  • Sample Space ($S$): $\{1, 2, 3, 4, 5, 6\}$ ดังนั้น $n(S) = 6$
  • ความน่าจะเป็น $P(E)$: $P(E) = \frac{n(E)}{n(S)}$
  • ความน่าจะเป็นช่วยบอก แนวโน้มโอกาส ไม่ใช่การการันตีผลจริง

กติกาเกม "นักเสี่ยงโชคพิชิตความน่าจะเป็น"

วัตถุประสงค์: ให้นักเรียนฝึกระบุ Sample Space, Event และคำนวณความน่าจะเป็น $P(E) = n(E)/n(S)$ เพื่อนำไปประเมินความเสี่ยงและวางแผนการตัดสินใจ

ขั้นตอนการเล่น (เล่นทั้งหมด 5 รอบ):

  1. เหรียญเริ่มต้น: แต่ละกลุ่ม/ผู้เล่น ได้รับ 10 เหรียญ
  2. เลือกบัตร: ในแต่ละรอบ เลือกบัตรเหตุการณ์ A, B, C หรือ D
  3. คำนวณ: เขียนระบุ $E, n(E), n(S)$ และ $P(E)$ ลงในใบบันทึกผล
  4. ทอยลูกเต๋า: ทอยลูกเต๋ามาตรฐาน 1 ลูก
  5. สรุปผล:
    • หากทอยได้ตรงตามบัตร: ได้รับเหรียญรางวัลตามที่ระบุบนบัตร
    • หากทอยไม่ตรง: เสีย 1 เหรียญ

ช่วงถอดบทเรียน (Debriefing) สำหรับครูผู้สอน

1. ปริภูมิของตัวอย่าง (Sample Space) ในการทอยลูกเต๋าคืออะไร?

คำตอบแนวทาง: $S = \{1, 2, 3, 4, 5, 6\}$ มีจำนวนผลลัพธ์ $n(S) = 6$

2. บัตรใดมีความน่าจะเป็นสูงที่สุด และบัตรใดมีรางวัลสูงสุด?

คำตอบแนวทาง: บัตร D มีความน่าจะเป็นสูงที่สุด (2/3) แต่รางวัลน้อย (+1) ในขณะที่บัตร C มีรางวัลมากที่สุด (+6) แต่มีความน่าจะเป็นต่ำที่สุด (1/6)

3. ผลการทอยจริงตรงกับความน่าจะเป็นที่คำนวณไว้เสมอไปหรือไม่?

คำตอบแนวทาง: ไม่เสมอไป เพราะความน่าจะเป็นบอกถึง "แนวโน้มเชิงทฤษฎีระยะยาว" ไม่ใช่การการันตีผลในการทอยรายครั้ง
